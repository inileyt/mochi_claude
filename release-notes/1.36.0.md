### What's new in 1.36.0

- 🎬 **Scan animation.** A new tool (Menu → Tools → Scan animation): pick an animated element and Mochi captures how it moves. A CSS animation keeps its real `@keyframes` and timing; an element moved by JavaScript (rAF, GSAP, Framer Motion…) is sampled frame by frame and rebuilt as an approximate `@keyframes`. You get a live preview, the CSS to copy or download, and a prompt to have Claude recreate it — all in your browser.
