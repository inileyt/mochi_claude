### What's new in 1.37.0

- 🗂️ **Tools menu, tidied up.** The Tools menu is now grouped by what each tool does — *Look at the page* (Scan this UI, Pick an element, Color picker, Font inspector), *Capture from the page* (Scan an image, Scan animation, Copy for Figma, Deep scan), *With Claude* (Live Edit, Guides, Bug report) and *Notes on this page*. Easier to find what you need.
- 🖼️ **`<canvas>` is understood now.** *Scan animation* recognises a `<canvas>` drawn in code (Canvas 2D / WebGL): it can't become CSS keyframes, so Mochi grabs a still frame and writes a prompt asking Claude to recreate it on a canvas with `requestAnimationFrame`. *Copy for Figma* exports a `<canvas>` as a picture (PNG), so canvas-based charts and logos come through.
- ⏳ **Real download progress for the AI model.** The on-device AI model page now shows an animated bar while Chrome prepares the download and a real percentage as it downloads, instead of an empty bar that looked stuck.
- 🔡 **Steadier text scanning.** Image Scan's OCR no longer lets an internal hiccup bubble up as an error — if a region can't be read it's simply skipped, and the languages you picked are honoured end to end.
