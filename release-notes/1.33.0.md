### What's new in 1.33.0

- 🧭 **A tidier menu.** The ☻ Mochi tab is now only about Mochi (level, Play, Catch stars, Focus, Pocket, design taste), and the ✦ Tools tab holds every tool under two clear headings — **On this page** and **In this chat**.
- 🔤 **Image Scan knows more fonts.** "Looks similar to" now compares against **44** bundled free fonts instead of 20 — more sans, serifs, monospace, display and handwriting faces — so the guess is closer, and Russian text matches better (several of the new fonts ship Cyrillic).
