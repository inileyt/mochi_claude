### What's new in 1.42.0

- 📄 **Deep scan now reads the source, not only the render.** The rest of the scan measures the page as it's drawn on screen. This new step keeps what lives in the files but may never show: your page's own CSS **verbatim** — every rule, every `@keyframes` (including ones the live scan never triggered because nothing on screen used them), and the media-query rules for widths you weren't viewing — plus a list of the page's scripts (the JavaScript behaviour a render can't reveal). An AI handed the spec then rebuilds from the real code instead of a reconstruction.
- 🗂️ **In the zip.** For **your own site** (the "my own site" box), the CSS ships as `source.css`, the HTML (where it's readable same-origin) as `source.html`, and the **real font files** the `@font-face` rules point at land in `fonts/` — so the rebuild uses the exact typeface, not a lookalike. `PROMPT.md` points the AI straight at all of them. For a site that isn't yours, the raw source and font files are **left out** (they hold the original copy, branding and licensed typefaces) — but `spec.json` still carries the source metadata: how many `@keyframes` are defined vs. actually used on screen, the stylesheet list with sizes, the `@font-face` count and the script list, so you can rebuild the behaviour with your own content.
