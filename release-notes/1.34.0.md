### What's new in 1.34.0

- ⚛️ **Export a picked element as a React or Vue component.** After *Pick an element*, the export tabs now include **React** (a JSX component) and **Vue** (a single-file component), next to CSS, HTML and Tailwind. Each carries the element's own styles (hover and keyframes included) and its label, ready to drop into a project.
- 🇦🇲 **Image Scan reads Armenian.** *Scan an image* now recognises Armenian text too, not just English and Russian — the Armenian OCR model is bundled, so it still works fully offline.
