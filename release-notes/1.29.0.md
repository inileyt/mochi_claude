### What's new in 1.29.0

- ✎ **Notes for every site:** Mochi holds a little notepad — notes for this page or the whole site, with `[ ]` checkboxes, autosave and pastel paper. He holds up a tiny paper when a page has notes. **All notes** lists them by site (search, open, delete, JSON / Markdown export and import), and **Send to Claude** offers a note on claude.ai (you press Enter). Optional **reminders on revisit**: after you allow it, a little Mochi peeks in on pages with a note. Notes never leave your browser.
- ◉ **Color picker:** Mochi's pipette picks any pixel — HEX / RGB / HSL / OKLCH and a name (HEX copied right away), the last 24 colors, a WCAG contrast check (thumbs up or a worried face), export as CSS / Tailwind / JSON.
- Aa **Font inspector (Alt+F):** Mochi puts on his glasses; point at text to see the font really used, size, weight, line height, spacing, color and contrast; click to pin, Copy CSS or Copy for AI. Your clicks never reach the page while inspecting.
- Each tool loads the first time you use it and runs nothing while it's off. New: an optional permission (only for reminders, asked from a click) and the Alt+F shortcut.
