### What's new in 1.39.0

- 🩹 **Live Edit paste fix.** A saved Live Edit request (and saved notes, bug reports, picked colours and deep-scan prompts) is now pasted into Claude **exactly as written**. Before, in a tab where that tool hadn't been loaded, it could fall back to a generic "rebuild this UI" prompt — so asking to *make something bigger* could come back as a pile of files instead. Now the exact request is always what Claude receives.
- 📱 **Responsive preview.** A new tool under **Menu → Tools → Preview → Responsive preview**. Mochi lays the page out at **phone (390)**, **tablet (768)** and **desktop (1280)** widths the way DevTools' device mode does — by emulating the viewport, so the page's **own `@media` breakpoints really fire** — takes a screenshot of each, and flags any width where the content **spills past the screen** (a horizontal scrollbar), showing how many pixels over. A **light / dark** switch re-previews with that colour scheme, and you can save any screenshot. It works on any page it can attach to, **claude.ai included**; the viewport emulation is cleared and the debugger detached the moment it's done, so nothing on the page is left changed.
