### What's new in 1.27.1

- 🔬 **Deep scan explains what went wrong** instead of showing an error code:
  - if Chrome allowed the permission but Mochi needs one restart to use it, a **Restart Mochi** button;
  - if DevTools (F12) or another debugging extension is already connected to the tab, what to close;
  - on pages Chrome protects (its own pages, the Web Store), that it can't work there;
  - a **Try again** button.
